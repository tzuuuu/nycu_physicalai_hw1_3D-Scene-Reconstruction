# M5：自製 ICP 與四組既有實驗比較

日期：2026-11-19（臺灣）。本次範圍依使用者確認：一樓 Baseline、一樓 C1、二樓 Baseline、二樓 sparse-v1，沿用既有設定只替換 ICP；不重跑 Open3D，不增加參數或 seed 實驗。使用者明確要求原 ICP 不可刪除或改寫。

## 規範與核心

權威依據為 `docs/assignments/HW1_3D Scene Reconstruction.pdf` §3.5、§4.1（第10–11頁）：自行實作最近鄰對應與剛體估計，說明實作方法並比較重建與執行時間；Bonus 與基本分分開。英文最終報告需說明搜尋、門檻、收斂與效能取捨。本次只產生 Bonus 方法、實驗與報告素材，不宣稱最終報告或 ZIP 已完成。

`utils.my_local_icp_algorithm` 採 Point-to-Point ICP＋Kabsch SVD；保留教師 TODO 全文並新增說明。SciPy `cKDTree` 提供近鄰索引與查詢，NumPy 提供陣列運算和 SVD；ICP 疊代、對應過濾、反射校正、旋轉／平移解、轉換累積、停止條件、最終指標均由本次程式實作，不呼叫 Open3D ICP。使用現成 KD-tree 不等於手寫樹結構，報告需明確揭露。

固定單次目標點雲只建一次索引，單執行緒查詢，不建立 N×M 全距離矩陣。每次以目前轉換查最近鄰，保留距離 < 1.5v 的對應；至少10組才估計更新。中心化互共變異矩陣 `H=XᵀY=UΣVᵀ`，`R=VDUᵀ`，其中 D 修正反射，`t=ȳ−Rx̄`，`T←ΔT T`。前兩奇異值不支持非共線幾何時回報退化，不把可用平面誤判為退化。最多60次更新，以相鄰疊代更新前平均內點距離的絕對變化 < 1e-6 m 停止；不同疊代的對應可能改變，這是啟發式停止條件，不代表姿態真實誤差已收斂。

最後以最終轉換重建對應，計算 source 支撐比例 Fitness、歐氏內點 RMSE 與對應索引。回傳迭代次數、終止原因及 success。空對應 RMSE=0 僅沿用指標表示，success=False；對應不足或退化時重建明確停止，不填假矩陣。

原 `local_icp_algorithm` 含說明、註解與實作逐字保持；其 Open3D Point-to-Plane、100次上限、fitness/RMSE 停止規則及原預設不變。只開通 `my_icp` 的既有分支並加上自製失敗檢查。提交前以原函式文字 SHA 及測試驗證。

## 保存、計時與驗收

主工具 `scripts/m5_bonus.py` 依 prepare→run 分階段；來源與資料先雜湊保全，四組各僅一次。三個新實驗與 `research_outputs/m5_bonus_01/` 若存在則拒絕覆寫，不自動重試。沿用既有程序樹 RSS 取樣監測器與獨立 watchdog，3 GiB門檻；這是取樣護欄，非作業系統硬上限。需要實際 ps 權限，沙箱內不取消監測硬跑。

以獨立 profile Observer 讀取函式回傳，不改寫既有 Observer 或原 ICP。每組保存同次完整地圖點／色、4×4位姿、相機中心、RANSAC與ICP變換、影格／配對事件、逐對 ICP 時間／疊代數／停止原因、原生PNG、實驗快照與原始評估值。繪圖樣本不替代完整地圖。

ICP 計時包含輸入驗證、陣列準備、樹建立、搜尋、SVD與最終指標；重建函式時間包含讀取、前處理、RANSAC、ICP、地圖整合及觀測，止於 map export 前；worker 包含匯入、宣告／驗證、評估、圖像、輸出與Turtle。全部標示邊界。

`scripts/m5_analysis.py` 僅離線分析，逐對比對歷史 RANSAC 初值；若不完全一致，不能把完整差異單獨歸因於ICP。比較 Mean L2、影格數、逐張／末張／最大誤差、記錄時間、記憶體、配對指標及地圖。二樓密度比較另提供共同204索引 Mean L2。每組單次、歷史不同時段／觀測邊界；歷史缺少純ICP時間，不報純ICP加速比或顯著性。

Point-to-Point 與 Point-to-Plane 目標、60／100次預算及停止準則不同；不能把效能／準確度差異當成單純程式語言效率。一樓原M2沒有同次完整地圖，保留原生圖；軌跡用先前核對相符的M3.0診斷來源明示標註，不拿B0地圖冒充M2。C1歷史地圖只有stride樣本，明示來源限制。地圖皆去天花板、估計紅色、GT黑色，共同座標不擬合；缺少表面GT，不報全樓層完整率。

驗收需包括：已知剛體／非單位初值／反射／離群值／失敗測試、官方 CLI Baseline與Selected合成驗證、Open3D回歸、原生監測測試、四組有效完成與Seal、因素／影格／配對一致、原函式與歷史來源不變、圖表視覺檢查、比較CSV與來源Manifest。
