正式取消 **P2-C Different Route**：不再採集第二條路線、不建立 P2-C Capture／Experiment、不安排 P2-C 重建。既有計畫與歷史文件保留原文；本紀錄為新增的決策，不將歷史計畫改寫成從未包含 P2-C。
