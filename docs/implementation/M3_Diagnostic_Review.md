## 重建與離線評估方法

正式 CLI 沒有保存相機中心或轉換矩陣；前 20 張 Preflight 不能補足後 171 張。因此依本次授權進行一次完整診斷重建：`version="open3d"`、`voxel_size=0.05`、`registration_seed=0`、`build_cloud=False`、`frames=None`，完整消耗原始 191 張影格。未傳入 GT，也沒有選取影格；`down_voxel=None` 及略過天花板裁切只因本次不建立地圖。所有配準參數沿用原函式與正式設定，沒有搜尋參數。

RANSAC／ICP 每對矩陣方向均為「目前影格 → 前一影格」，累積位姿 `P_i=P_(i-1) T_i`。先保存 191 個預測相機中心、190 對矩陣及品質因素，重建回傳後才呼叫原評估函式載入 GT。GT 與預測不做最佳旋轉、平移或尺度擬合。

離線完整 GT 位姿採以下固定轉換，其中 `A=diag(1,-1,-1)`、世界相機旋轉為 `R_i`、世界中心為 `t_i`：

- GT 旋轉：`Q_i = A R_0^T R_i A`。
- GT 中心：`c_i = A R_0^T (t_i-t_0)`。
- GT 相對位姿：`G_i = inverse(GT_(i-1)) GT_i`，與 `T_i` 同方向、同一前相機座標系。
- 逐幀 L2：`||P_i.translation-c_i||`；累積平均為 1–i 的平均，另列 `L2_i-L2_(i-1)`，後者可為負值，並非累積路徑長或局部配準誤差。
- 相對平移誤差：`||T_i.translation-G_i.translation||`；相對旋轉誤差：`angle(G_i.rotation^T T_i.rotation)`，以度表示。
- ICP 對粗轉換的修正：平移向量差的範數，以及 `angle(RANSAC.rotation^T ICP.rotation)`。它描述兩個估計的差異，不等於對真實位姿的誤差。

以 190 個配對的 Spearman 相關描述因素與逐幀 L2、L2 增量、局部平移／旋轉誤差的關係。單幀點數以 current frame 與 pair 對齊。連續影格並非獨立樣本，絕對 L2 又含先前累積的偏差，因此不將相關當作因果、不報獨立樣本顯著性。第一張沒有相鄰配準誤差，不以零代填 pair。

RGB 明暗異常是可見觀察，但本核心的 RANSAC 使用幾何 FPFH，ICP 使用點與法向量，**沒有用 RGB 做光度配準**；所以 RGB 偏暗本身不是已證實的直接機制。RGB 異常可能與同步的深度缺失／擾動共同出現。沒有未受擾動的同姿態深度對照，本次也不能把所有深度偏差稱為已量出的感測雜訊。

## 有量測支持、仍待驗證的原因假說

1. **優先：牆面幾何歧義與深度支撐變化共同使 RANSAC 選到近上下顛倒的解。** 支持：103／104 近平面視野、有效深度下降、已保存 RANSAC 就錯約 176°，ICP 後約 180°。尚缺：FPFH 候選唯一性、法向量條件與正確解相對殘差的直接比較，不能宣稱某個窗框或同一平面特徵就是實際被錯配的點。
2. **局部缺失／深度擾動使 103–105 的穩定幾何訊息減少。** 支持：有效深度及 RGB-D 的同步變化、104／105 局部錯誤、RMSE 高值。反例：114 更嚴重缺失卻配準準確；所以缺失不充分也未證明必要。若介入只移除低有效深度影格卻沒避開失敗，便削弱此假說。
3. **純轉向時近牆視野造成可觀測性降低。** 支持：103–105 原地轉向、窄深度分布與近平面形狀；104 深度 p10–p90 僅約 1.160–1.727 m。反例：147–151 更扁平且也有轉向，仍沒有同級翻轉；需要保持其他條件固定的對照，不能把所有轉向影格判壞。
4. **已確認的傳播機制：錯姿態經連乘帶到後續位移。** 保存矩陣、累積旋轉誤差及後段小局部誤差共同支持此機制。它解釋後段 L2 上升，卻沒有回答最初為何選錯特徵；不把傳播機制與感測資料原因混為一談。
